# ADR 0001 — Record architecture decisions

Date: 2025-12-01
Status: accepted

## Context

We need to record the architectural decisions made on this project to maintain
shared understanding as the team and codebase grow.

## Decision

We will use Architecture Decision Records (ADRs) as described in Michael
Nygard's article. Each ADR lives under `docs/adr/`, is numbered sequentially,
and is immutable once accepted (changes are made by superseding ADRs).

## Consequences

* Anyone joining the team can read the history of decisions chronologically.
* Decisions that turn out to be wrong are visible alongside the decisions that
  superseded them.
